# 纸间日历 · 墨竹与海浪

双击 **PaperCalendar.exe**，无需脚本或额外安装依赖。适用于 Windows 10 / 11，使用系统 .NET Framework 4.x。

## 日历与备忘

点击日期查看当天备忘，点击“写下计划”添加；点击内容编辑，勾选完成，× 删除。有计划的日期在米黄主题显示蓝字，海浪主题显示赭橙字。

## 每日楷体小贴士

内置 **3653 条互不重复的古诗文短句**，温暖与励志内容混排，每天只显示一句。删除了分类、编号和第二条生活提示。首次使用当天开始，每个自然日换一句，考虑闰日，可以覆盖十个日历年。持续运行时自动跨日更新，短句无需联网，用完后从头循环。

网上古诗文来自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，附带 MIT 许可。每条作者、作品和原始数据地址保存在 tips-with-sources.json 中。悬停在每日短句上查看出处，右键“短句来源与许可”查看说明。筛选排除了明显消极、战争和宫廷等主题，并做了去重及繁简转换；异体字及版本差异按数据源保留。

小贴士使用系统楷体 KaiTi。未安装楷体的电脑会使用系统替代字体。

## 拖动与呼出

- 无标题栏、纸面细纹理和系统轻阴影。
- 左键按住纸面空白、标题、日历或小贴士区域拖动；松开后记住位置。
- 右键“隐藏”收起；点击托盘图标或 Ctrl + Alt + D 呼出 / 收起。
- 右键“关闭程序”彻底退出，备忘仍保留。
- 托盘图标可能在隐藏图标菜单中，可以拖到常显区域。
- 快捷键被其他程序占用时，仍可以从托盘呼出。
- 阴影由 Windows 桌面合成器显示，关闭系统阴影效果可能影响显示。

## 右键切换主题

右键纸面或托盘图标 → **切换主题** → **米黄墨竹 / 蓝色海浪**。主题自动保存，下次启动沿用。蓝色主题采用浅蓝纸面、深靛文字、赭橙待办，保留红色假日和黑色调休标记。切换不影响备忘、每日短句进度、位置及缩放。海浪为《神奈川冲浪里》浮世绘风格插图，使用内置 imagegen 生成，源图 assets/ukiyo-wave.png，完整提示词见 assets/wave-generation-prompt.md。

## 等比例缩放

右键纸面或托盘图标 → **等比例缩放** → 选择 **50%、60%、70%、80%、90%、100%**。100% 为原始大小（830 × 700），50% 为 415 × 350。

日历、农历、文字、待办控件与主题插图按同一比例缩放，日期点击区域同步调整；反复切换大小不会累积布局偏差。大小自动保存，重启仍保留。右键菜单和备忘编辑弹窗保持正常大小，方便选择和输入。

## 排版、农历与提醒

按照手绘布局：上方左侧日历、右侧待办；下方左侧依次是待办倒计时、节假日倒计时、每日一句、快捷键提示，右下角随主题显示透明底墨竹或浮世绘海浪。

- 阳历数字下方显示农历日期，农历初一显示月份；支持闰月。
- 中国大陆放假日：红字，右上角“假”；调休工作日：黑字，右上角“班”。普通周末不额外标成法定假日。
- 有任何计划的日期优先用主题待办色（米黄主题蓝色、海浪主题赭橙色），已完成的计划仍保留该颜色；“假 / 班”标记不受影响。
- 提醒只关注 **今天之后最近一天的未完成计划**；同一天多项合并计数。忽略更远的计划、当天、过去和已经完成的计划。所有计划完成时显示“已完成所有待办”；仅有当天或过去的未完成计划时显示“暂无未来待办”。
- 节假日倒计时按已公布的放假区间计算；正在放假时显示剩余假期天数。
- 内置 2026 年官方安排，来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn)。程序启动后在后台尝试更新当年、下一年的数据，联网成功后缓存到 `%LOCALAPPDATA%\PaperCalendar\holidays`；右键“更新节假日”可更新当前所看年份。
- 尚未公布的年份只显示下一节日的参考日期并提示“放假安排待公布”，不会猜测“假 / 班”。下载失败继续使用本机数据。清明参考日期按太阳黄经近似算法计算，实际放假以官方公告为准。
- 悬停日期查看农历、假期及计划信息。农历范围 1901—2100 年。

墨竹使用内置 imagegen 生成并嵌入 EXE，源图在 assets/ink-bamboo.png，完整生成提示词与方式见 assets/generation-prompt.md。

## 开机自启动

首次正常运行会启用当前 Windows 用户的登录自启动，无需管理员权限。程序复制到 `%LOCALAPPDATA%\PaperCalendar\PaperCalendar.exe`，注册到当前用户 Run 项。原下载文件移动后仍可自启动。

右键“开机自启动”可勾选或取消。Windows 可能略微延迟登录启动。关闭程序不会取消自启动，取消勾选才会停用。

## 本机数据

- `%LOCALAPPDATA%\PaperCalendar\plans.xml`：备忘。
- `%LOCALAPPDATA%\PaperCalendar\settings.xml`：短句起始日和窗口位置等。
- 保存时保留上一版本 `.bak`。旧版备忘格式兼容，不会清空。

不包含定时通知或云同步。不要在多个 Windows 会话中同时编辑同一数据文件。

## 构建与验证

build-corpus.ps1 下载公开数据、筛选去重并保存来源，缓存保留用于复核。build-exe.ps1 用系统自带编译器生成 EXE，嵌入短句、节假日、墨竹与许可。verify.ps1 在隔离目录验证十年去重与循环、备忘保存读取、农历闰月、日期颜色与标记、未来最近待办、跨年节日倒计时、位置记忆、跨日换句及托盘呼出，不设置自启动。check-holiday-update.ps1 单独验证联网下载、校验与缓存。
